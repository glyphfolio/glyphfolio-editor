# Native feasibility evidence

The initial demo screenshot, when generated, is a render from the original native egui surface and synthetic sample Markdown. It demonstrates visible rendering only. It is not evidence of real IME composition, VoiceOver editing, full script support, bidi, clipboard interchange, or large-document performance.

The screenshot run uses the local system font supplied with `--font`; no system font is redistributed by this repository. Build identity, command, and output are recorded in `../VALIDATION.md`.


Historical text logs have local workspace/home paths replaced by `<workspace>` / `<home>` for public distribution. Results and executable hashes are retained. Screenshots use synthetic editor fixtures. Raw local backups are excluded under `target/`.
